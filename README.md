# 🏢 AI 합동 비서실

Roy · ChatGPT · Muse · Gemini 4인 전용 합동 비서실 웹앱.
정적 파일 3개로 동작하며, 서버·가입 없이 GitHub Pages에서 바로 열립니다.

- 🏢 **오피스 맵** — 픽셀 아트 비서실에 4개 캐릭터가 배치되어 움직이고 말풍선을 띄웁니다. 캐릭터를 클릭하면 상태(대기 중 / 검토 중 / 발언 완료)가 바뀌고 최근 발언 요약이 표시됩니다.
- 💬 **회의실** — 안건 등록, AI별 의견 추가, 찬성 / 기각 / 보류 투표와 실시간 집계 바. 슬랙·채팅 로그를 붙여넣으면 `[Roy]` `[ChatGPT]` `[Muse]` `[Gemini]` 말머리별로 자동 정리해 안건에 넣습니다.
- 🛠️ **작업실** — `ALPHA SHIELD v3.2` 스펙 카드(8종목 · 2슬롯 · 5중 방어막)와 `소액 코인 매매 봇` 진행 상태 보드.

## 저장

- 기본: 브라우저 `localStorage` (추가 가입 없이 즉시 동작)
- 선택: 상단 **⚙️ DB 연동**에 Firebase Realtime Database URL을 넣으면 REST API로 실시간 클라우드 동기화

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 픽셀/도트 오피스 테마 |
| `app.js` | 상태·스프라이트·투표·붙여넣기 파싱·DB 동기화 |

## 메모

- 공개 저장소이므로 API 키·전화번호·계좌정보 등 민감한 값은 넣지 않습니다. DB URL을 쓸 경우에도 공개 규칙이면 누구나 읽을 수 있으니 개인정보는 넣지 마세요.
- 스펙 수치는 공개 문서에 적힌 값만 표시합니다.
